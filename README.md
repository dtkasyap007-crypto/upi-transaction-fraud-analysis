# UPI Transactions & Fraud Analysis Dashboard
## Project Overview
An interactive Power BI dashboard designed to analyze UPI transactions and identify fraud patterns. The dashboard provides insights into transaction volume, fraud transactions, transactions status, user demographics, and transaction behaviour.
## Objectives
- Analyze overall UPI transaction activity
- Identify fraudulent transactions
- Understand transaction patterns by time and day
- Analyze transactions status and types
- Explore fraud patterns across different categories and user groups
- Provide an interactive dashboard for data-driven decision making
